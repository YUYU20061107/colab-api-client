# Privacy Policy — Colab API Client

_Last updated: 2026-11-20_

## Overview

Colab API Client is a personal, single-user application operated by its owner. It is used solely to manage the owner's own Google Colab resources via the official Google Colab API.

## Data accessed

With the owner's authorization (OAuth scope `https://www.googleapis.com/auth/colaboratory`), the application accesses only the owner's own Google Colab data: runtime configurations, the owner's runtime sessions, and Colab subscription status.

## How data is used

Data accessed through Google APIs is used only to perform the Colab management operations the owner requests (such as creating or deleting a runtime). The application:

- does not sell or rent any data;
- does not share or transfer data to any third party;
- does not use data for advertising;
- does not retain Colab data beyond what is needed to complete the requested operation.

OAuth credentials are stored in a secure credential vault under the owner's control and are never published or shared.

Colab API Client's use and transfer of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

## Revoking access

The owner can revoke the application's access at any time from the Google Account permissions page: https://myaccount.google.com/permissions
